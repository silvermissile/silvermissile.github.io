# 你好，数字花园

这是重建后的第一篇文章。

## 为什么重建

旧博客基于 Jekyll + Hux Blog 主题，搭建于 2019 年，主要记录大数据相关的技术笔记。搁置了近六年后，技术栈已经全面过时：

- Bootstrap 3、jQuery 等前端依赖远超生命周期
- Travis CI 免费版已不可用
- Google Analytics UA 已停用
- 本地甚至无法构建（Ruby 版本不兼容）

更重要的是，2026 年的内容创作环境已经发生了根本变化——AI 正在改变信息的生产和消费方式。

## 为什么选择 Quartz

在 Jekyll、Hugo、Hexo、Quartz、MkDocs 等方案中，选择 Quartz 5 的核心理由：

1. **Obsidian 原生兼容**：支持 WikiLink、双向链接、Callouts、关系图谱
2. **同时兼容标准 Markdown**：用 VS Code 写也完全没问题
3. **AI 友好**：静态生成、语义化 HTML、内置 RSS 和 Sitemap
4. **零成本部署**：GitHub Pages + GitHub Actions，推送即发布

## 内容方向

不再做"技术说明书"式的内容。AI 时代，纯信息型内容的价值正在归零。

新的方向是：

- **个人化实战案例**：展示"做成了什么"，而不只是"怎么做"
- **带观点的技术思考**：表达判断和偏见，而非中立的知识整理
- **知识网络**：通过双向链接构建有机的知识体系

## FAQ

**Q: 旧文章还在吗？**
A: 旧文章已归档。部分有价值的内容会以更新的形式重新发布。

**Q: 这个博客用什么写的？**
A: Obsidian 和 VS Code 混合使用，内容存储在 GitHub，通过 Quartz 5 生成静态页面。

**Q: 为什么叫"数字花园"？**
A: 数字花园强调知识的生长和连接，文章不是一次性发布的产品，而是持续培育的种子。
